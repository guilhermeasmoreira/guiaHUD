# Referências visuais dos temas do HUD

Estas três imagens são a direção visual aprovada para temas futuros. O tema atualmente implementado continua sendo **Padrão minimalista**. Ao criar os novos temas, preserve a disposição compacta dos componentes e as funções existentes do HUD; use as imagens para cores, contornos, ícones, contraste e acabamento.

| Tema | Referência | Direção visual |
| --- | --- | --- |
| Fogo | [HUD de fogo](referencias/hud-fogo.webp) | Fundo quase preto, contornos de brasa em laranja e vermelho, brilho quente e pequenos detalhes de chama. |
| Malefic | [HUD malefic](referencias/hud-malefic.webp) | Fundo preto arroxeado, bordas violeta, ícones sombrios e detalhes verdes pontuais. |
| Gelo | [HUD de gelo](referencias/hud-gelo.webp) | Fundo azul escuro, molduras cristalinas azul e ciano, brilho frio e detalhes de floco de neve. |

As imagens mostram o conjunto completo de perfil e alvo, menu, boss, Hunt Analyzer, habilidades e chat. Use a mesma linguagem visual entre esses componentes em cada tema. As imagens são referências de design e não representam recursos novos já implementados no jogo.
